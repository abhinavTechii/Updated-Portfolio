## Features

- Responsive layout for desktop, tablet and mobile
- Dark and light theme with a toggle (your choice is remembered)
- Typing animation in the hero section
- Floating navbar that highlights the section you are viewing
- Scroll progress bar, scroll reveal effects and back-to-top button
- Skills, projects, education timeline and certifications sections
- Contact form that opens your email app with the message pre-filled
- Accessibility basics: skip link, keyboard focus styles, and reduced-motion support

## Run locally

1. Clone the repository:
   ```bash
   git clone https://github.com/abhinavTechii/Updated-Portfolio.git
   cd Updated-Portfolio
   ```
2. Open `index.html` in your browser, or use the VS Code **Live Server** extension for auto-reload.

## Deploy with GitHub Pages

1. Go to **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and the `/ (root)` folder, then save.
4. After a minute the site is live at the URL at the top of this file.

## Customise

- **Text and sections:** edit `index.html`.
- **Colours and fonts:** change the variables under `:root` at the top of `style.css`.
- **Typing roles:** edit the `words` list in `script.js`.
- **Contact email:** change `MY_EMAIL` in `script.js`.
- **Photo:** replace `images/profile.jpg`.
